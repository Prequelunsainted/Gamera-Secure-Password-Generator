# 🐢 Gamera — Gerador de Senhas Seguras

![Python](https://img.shields.io/badge/Python-306998?style=for-the-badge&logo=python&logoColor=white)
![CustomTkinter](https://img.shields.io/badge/CustomTkinter-Dark_Theme-blueviolet?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

O **Gamera** é uma aplicação desktop desenvolvida em Python para geração de senhas forte e criptograficamente seguras. O projeto possui uma interface moderna em modo escuro com a temática inspirada no lendário Kaiju Gamera, permitindo controle total sobre o tamanho e o tipo de caracteres da senha.

---

## 🚀 Funcionalidades

- 🔒 **Geração Criptográfica Segura:** Utiliza o módulo `secrets` nativo do Python (mais seguro que geradores aleatórios padrão).
- 🎛️ **Controle Personalizado:** Ajuste do tamanho da senha (8 a 32 caracteres) e seleção de grupos (Maiúsculas, Minúsculas, Números e Símbolos).
- 🎨 **Interface Gráfica Moderna:** Desenvolvida com **CustomTkinter**, suporte a redimensionamento e plano de fundo personalizado.
- 📋 **Cópia Instantânea:** Botão para copiar a senha gerada diretamente para a área de transferência.

---

## 🛠️ Tecnologias Utilizadas

- **[Python 3](https://www.python.org/):** Linguagem principal.
- **[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter):** Interface gráfica moderna.
- **[Pillow (PIL)](https://python-pillow.org/):** Manipulação e renderização da imagem de fundo.
- **`secrets` & `string`:** Módulos nativos para geração de caracteres seguros.
